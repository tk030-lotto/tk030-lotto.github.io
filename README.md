# Zero Dev

Zero Dev は、個人開発で制作したツール・ソフトウェア・技術作品をまとめて公開し、実際に利用できる場所として運営するサイトです。

正式URL: [https://zero-dev.jp/](https://zero-dev.jp/)

## 目的

単なるポートフォリオや受託開発サイトではありません。

- 自作ツールを公開する
- 実際に利用できる形で紹介する
- GitHub、note、My Tools など既存の公開先へつなぐ
- AI開発相談やOSS要望の入口を設ける
- 開発を支援したい人からの投げ銭（支援）を受け付ける

基本方針は、**自分が作りたいものを作り、公開できるものを公開する。見てもらえれば嬉しい。面白く、条件の合う依頼があれば受ける。依頼がなくても自分の開発を続ける。** というものです。

## サイト構成

| URL | 内容 |
|---|---|
| `/` | HOME |
| `/tools/` | ツール一覧 |
| `/tools/[name]/` | ツール個別ページ |
| `/consult/` | 相談・要望・支援 |
| `/privacy/` | プライバシーポリシー |
| `/disclaimer/` | 免責事項 |

GitHub、note、My Tools はフッターから外部リンクとして案内します。

## ツールの掲載

完成済みで、公開できる品質を満たした自作ツールを、1つずつ手動で掲載します。
（掲載管理ツールや `ZERO-DEV.md` のような自動化の仕組みは、現状では使用しません）

個別ページには以下の情報を掲載します。
- 用途（何ができるか）
- なぜ作ったか（開発の背景・動機）
- カテゴリー
- スクリーンショット / デモGIF
- デモ / 利用URL
- GitHub URL
- note URL
- ライセンス

ツール一覧ページ（`/tools/`）、HOME の総掲載数、`sitemap.xml` は、個別ページのメタデータ（`data-*` 属性）を Python スクリプト（`scripts/generate_list.py`）で読み取り、自動生成します。

最初の掲載は、品質を確認できたツール1本から始め、確認を行いながら1つずつ追加します。

## 相談・要望・支援

`/consult/` ページにて、以下を案内します。

1. **AI開発相談**（初心者からの質問を含む）
2. **OSS要望**（「こんなの作ってもらえますか？」というリクエスト）
3. **開発支援**（note のチップ機能、および GitHub Sponsors への導線）

個別の開発のご依頼は、「個別にご相談ください」程度の案内にとどめ、料金や条件は掲載しません。

フォーム送信は相談・要望の受付であり、契約の成立ではありません。すべての相談・要望への返信や、要望の開発を保証するものでもありません。

フォームは外部サービス（Google Forms）を利用し、Zero Dev 本体にはフォーム処理用のバックエンドを持たせません。

## 技術構成

- HTML / CSS / Vanilla JavaScript（公開されるページは静的HTML）
- GitHub Pages（リポジトリ: `tk030-lotto.github.io`、カスタムドメイン: `zero-dev.jp`）
- ビルド処理なし
- 一覧・総掲載数・sitemap の生成のみ Python スクリプト（標準ライブラリのみ）を使用
