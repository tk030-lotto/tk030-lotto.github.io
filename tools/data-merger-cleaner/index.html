Excel・CSV結合クレンザー

Excel / CSV Merger & Cleaner

ツールを利用する / コードを見る

ツールを開く（Web版） GitHub リポジトリ note 解説記事（準備中）

こんなときに

部署や取引先ごとに、列の並びや表記が異なる Excel・CSV ファイルを 1 つの表にまとめたいときに使います。00123 のような先頭の 0 を残したまま結合できます。ファイルの内容は外部に送信せず、ブラウザ内で処理します。

できること

  • .xlsx / .xls / .csv のファイルを複数選び、1 行目の見出し名をもとに縦に結合します。
  • 空の見出しは 列N、同じファイル内で重複した見出しは 見出し(2) として、データを残して結合します。
  • CSV の 00123 や、Excel の数値・日付・真偽値の型を保持します。
  • 法人表記（(株) → 株式会社、(有) → 有限会社）、スペース、全角英数字・ハイフンの表記揺れを、設定ごとにオン・オフして整えます（カタカナの長音記号「ー」は変換しません）。
  • 結合結果の先頭 50 行を確認し、CSV（UTF-8 BOM 付き）または Excel（.xlsx）で全件を保存します。

向かないこと・注意

  • 対応形式は .xlsx、.xls、.csv です。パスワード保護や暗号化されたファイルは読み込めません。
  • 複数シートの Excel ブックは、先頭シートだけを取り込みます。
  • プレビューは先頭 50 行までです。保存するファイルには全行が入ります。
  • ファイルサイズや行数の上限チェックはありません。大きいファイルでは、処理に時間がかかる場合があります。
