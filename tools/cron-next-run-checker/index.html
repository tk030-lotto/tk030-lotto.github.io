cron式 次回実行日時チェッカー

cron-next-run-checker

ツールを利用する / コードを見る

ツールを開く（Web版） GitHub リポジトリ note 解説記事（準備中）

こんなときに

定期実行の設定に使う cron 式（実行スケジュールを表す5つの数字や記号の並び）は、書いた本人でも次の実行日時を頭の中で追いにくいことがあります。曜日の番号や間隔の指定を取り違えると、意図しない時刻に動いて初めて気づくケースがあります。本ツールは、式を入力欄に入れるだけで日本語の意味と次回の実行日時を確認できます。

できること

  • 5フィールドの cron 式（分・時・日・月・曜日）の意味を日本語の一文で表示します。
  • 基準日時より後の次回実行日時を最大5件、昇順で一覧表示します。
  • 入力欄や基準日時を変更すると、ボタンを押さずにその場で再計算されます。
  • 基準日時を変更でき、「現在時刻に戻す」ボタンで現在時刻へ戻せます。
  • 式に誤りがある場合は、どのフィールドの何が問題かを日本語で表示します。
  • 入力した式はブラウザ内のみで処理し、外部サーバーへ送信しません（保存も行いません）。

向かないこと・注意

  • 秒フィールドを含む6フィールド形式、@daily などの別名表記、月や曜日の英字名（JAN・MON など）、単一の値を左辺とする間隔指定（5/15 など）には対応していません。
  • 計算はお使いのブラウザのローカル時刻で行います。協定世界時（UTC）で動く定期実行環境で試す場合は、時差を読み替えて確認してください（例: 日本時間 9:00 は UTC 0:00）。
  • 探索上限は基準日時から50年後の年まで（かつ内部探索反復上限まで）です。一致した日時が5件に満たない場合は、見つかった件数のみ表示します。
  • 夏時間（DST）のある地域では、存在しない時刻はスキップされ、重複する時刻は1回だけ表示されます。
  • 入力内容は保存されません。ページを再読み込みすると入力は消えます。

なぜ作ったか

定期実行の設定は、毎週のつもりが毎日になっていたり、曜日の番号をずらして指定していたりするミスが起きがちです。設定を本番へ入れる前に、式の意味と実際の実行予定をその場で並べて確認できる単機能の画面があれば役立つと考え、ブラウザだけで動く形にしました。
