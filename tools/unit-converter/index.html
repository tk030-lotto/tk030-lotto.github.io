単位変換ツール

Unit Converter - 16カテゴリの単位換算

ツールを利用する / コードを見る

ツールを開く（Web版） GitHub リポジトリ note 解説記事（準備中）

こんなときに

料理やDIY、部屋の間取り確認で cm・m²・坪・畳などを換算したいときに使えます。海外旅行や輸入品で inch・mile・lb・℉・gallon・mpg が出てきたときや、学習・業務で圧力・仕事率・電気・データ容量・尺貫法を確かめたい場面にも対応します。

できること

  • 長さ・面積・重さ・体積・温度・速度・時間・データ容量・圧力・エネルギー・仕事率・周波数・角度・電気・燃費・日本の慣用単位の 16 カテゴリを換算できます。
  • 「変換元」に半角の数字を入れると、そのまま「変換先」に結果が出ます。
  • 「⇅」で変換元と変換先の単位を入れ替え、「📋 結果をコピー」で結果をコピーできます（自動コピーできない環境では手動コピー用の入力欄を出します）。
  • 「よく使う変換」から、m² ⇄ 坪、m² ⇄ 畳、km ⇄ mile、kg ⇄ lb、℃ ⇄ ℉、km/L ⇄ mpg を 1 回押すだけで呼び出せます。
  • 畳（江戸間: 1.5488 m²）、米国液量、US mpg、固定暦日数（1月=30日・1年=365日）など、規格で差が出るカテゴリでは画面内に注記を出します。
  • 外部サーバーへの通信は行いません。入力と計算はブラウザ内で処理します。

向かないこと・注意

  • 計算結果は倍精度浮動小数点で計算し、有効桁数 8 桁で丸めて表示します（極大・極小値は指数表記になります）。
  • 地域や規格で定義が異なる単位は、画面内の注記に示した基準で計算します。取引や設計の判断には公的規格や一次資料を併せて確認してください。
  • 入力内容や履歴を保存する機能はありません。ページを再読み込みすると初期状態に戻ります。
  • 半角の数字以外や、燃費カテゴリでの 0 以下は変換できません（画面内に理由を表示します）。
