割引率らくらく計算

連続割引の支払額と実質割引率を計算

ツールを利用する / コードを見る

ツールを開く（Web版） GitHub リポジトリ note 解説記事

こんなときに

セール価格にクーポンを重ねるなど、割引が2回以上あるときの支払額を知りたい場面で使います。「50%OFFのあとに30%OFFなら、合計80%OFF」とは計算されません。2回目の割引は、1回目の割引後の価格にかかります。このツールは、その計算を段階ごとに表示します。

できること

  • 通常価格と、1つ以上の割引率を入力すると、最終支払額・実質割引率・お得になった金額を表示します。
  • 割引の段階ごとに、掛け率（× 0.50 など）、引かれた金額、割引後の価格を並べて表示します。
  • 割引を2つ以上かけたときは、単純に足した割引率と、実質の割引率の違いを表示します。
  • 端数処理を「四捨五入」「切り捨て」「切り上げ」から選べます。
  • 計算結果のコピーと、入力条件を含むURLの共有ができます。

向かないこと・注意

  • 計算結果は参考値です。店舗やサイトによって、割引の適用順や端数の扱いが異なることがあります。実際の金額は、各店舗の決済画面で確認してください。
  • 税の計算と、ポイント還元の計算はできません。
  • 割引率は0〜100の範囲で計算します。範囲外の数値は、0または100として扱います。
  • 途中経過の金額は、段階ごとに端数処理して表示します。最終支払額は、小数のまま計算したあとに端数処理します。そのため、途中経過の差し引きと最終支払額が、1円ずれることがあります。
  • 入力内容は、お使いのブラウザに保存されます。外部のサーバーには送信しません。

なぜ作ったか

複数の割引を順番に適用したときの、最終支払額・実質割引率・お得になった金額を計算するために作りました。
