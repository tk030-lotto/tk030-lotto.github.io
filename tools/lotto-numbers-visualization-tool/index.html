ロト＆ナンバーズ可視化ツール

過去出目の構造解析と出目表表示

ツールを利用する / コードを見る

ツールを開く（Web版） GitHub リポジトリ note 解説記事

こんなときに

ロト系とナンバーズ系の過去出目データを、1つの画面で見比べたいときに使います。合計値、奇偶比、引っ張り（前回と同じ数字）、スライド（前回の前後1の数字）などの指標をまとめて確認したいときや、過去の任意の回号を基準にして当時の傾向と出目表を振り返りたいときに役立ちます。

できること

  • 構成指標と出現頻度の集計: 奇偶比、合計値、連番、引っ張り、スライド、ナンバーズのパターン型（シングル・ダブル等）と、直近 10〜100 回の出現頻度分類を表示します。
  • 出目表マトリクスと絞り込み: 回号ごとの当選数字を色分けして表示します。ロト系では 10 刻みの数字帯タブで列を絞り込め、PC 表示とスマホ表示を切り替えられます。
  • 拡張分析とグラフ: 前々回からの周辺流入（ロト系）、桁別ヒートマップ（ナンバーズ系）、共起ペア Top 10、未出現スパン上位 15 件、合計値推移グラフを表示します。
  • 過去回号の基準切替とレポート出力: 過去の回号を選んで再計算できます。解析結果は Markdown 形式でクリップボードにコピーできます。

向かないこと・注意

  • 買い目の自動生成や当選予測を行うツールではありません（過去データの統計・可視化のみ、無保証）。
  • 起動時や更新時に抽せん結果データを外部から取得します。通信できない場合は内蔵データ（2026-10-30 抽せん分まで）で表示します。
  • 集計回数や基準回号などの設定はブラウザに保存されません。ページを再読み込みすると初期状態に戻ります。
  • 未出現スパンランキングカードは上位 15 件までを表示します。

なぜ作ったか

もともと手元で使っていた Python 版の可視化ツールの機能をブラウザへ移し、ナンバーズ3・4の分析機能と1つの画面に統合するために作りました。
