CSV Mojibake Fixer

こんなときに

Windows 日本語版 Excel で CSV ファイルを開いたときに、文字が化けることがあります。UTF-8 と Shift-JIS の間で、文字コードを変えて保存し直したいときにも使えます。ファイルを画面に置くと、文字コードを判定して、先頭 50 行をプレビューに表示します。

できること

  • UTF-8（BOM なし・BOM あり）と Shift-JIS を自動で判定して表示します。
  • 先頭 50 行を表形式でプレビューに表示します（保存時は全行・全データを出力します）。
  • 「自動判定に戻す」「Shift-JIS (Excel用)」「UTF-8」で、文字コードを手動で切り替えられます。
  • 「Shift-JISで保存 (Excel用)」「UTF-8で保存」で、選んだ文字コードの CSV として保存できます。
  • UTF-16（BOM 付き）、解釈できない文字、EUC-JP の可能性があるときは、プレビューの上に警告を表示します。
  • ファイルの内容は外部に送信しません。読み込み・判定・プレビュー・変換は、お使いのブラウザ内で行います。

向かないこと・注意

  • 対応する文字コードは UTF-8 と Shift-JIS のみです。UTF-16（BOM 付き）や EUC-JP のファイルは、警告が出ても正しく読み込めません。
  • Shift-JIS で表せない文字（絵文字、波ダッシュ「〜」、マイナス記号「−」、半角円記号「¥」など）は、保存時に確認画面が出ます。承認すると「?」に置き換えて保存し、キャンセルすると保存しません。
  • ファイルサイズは 50 MB まで、プレビューは先頭 50 行までです。プレビュー表の区切り文字はカンマ（,）固定です。
  • Excel 実機での表示確認は未実施です。環境によって、表示が異なる場合があります。
