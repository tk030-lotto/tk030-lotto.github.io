Tool Catalog System (要Python)

⚠️
ご利用前の重要なお知らせ
本ツールはブラウザで動くWebツールではありません。手元のPython環境で動作する開発支援システムです。

用途

note連携で自作ツールの一覧を自動更新する静的カタログシステムです。noteの記事情報を取得し、静的HTMLサイトとしてツール一覧をビルド・更新します。ブラウザ単体で完結するWebツールではなく、手元のローカルPC（Python実行環境）で動作させる仕組みです。

なぜ作ったか

個人開発のツールが増えるにつれて、一覧ページの手動更新やnote記事との同期、メタデータの整合性維持が煩雑化する課題を解決するために作成しました。note APIとの連携、手動編集箇所を壊さない非破壊マージ、Windows環境特有の文字コード（UTF-8 / CP932）問題の解消など、運用保守を自動化・堅牢化しています。

注意事項・限界

  • 本システムは静的HTMLジェネレーターであり、手元のローカルPC（Python 3.x環境）で実行する必要があります。
  • カテゴリの追加や構成変更を行う場合は、コード（Pythonスクリプト）の修正が必要です（詳細はリポジトリのREADMEをご参照ください）。
  • note記事の同期・更新にはインターネット接続が必要です。
