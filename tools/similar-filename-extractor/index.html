こんなときに

フォルダの中に、コピーや版の違いで増えたファイルが散らばっているとき。ファイルを消したり動かしたりする前に、似た名前同士を並べて目で確かめたいときに使います。

できること

  • フォルダを選んで、その中にあるファイル名から似た名前同士をグループで一覧表示します（例：report.pdf と report (1).pdf、企画書.docx と 企画書_20261113.docx など）
  • テキストの貼り付けや、.txt / .csv ファイル（UTF-8 / Shift-JIS）の読み込みからも調べられます
  • 違いの種類（コピー表記／版表記／日付／数字／拡張子／表記ゆれ／パスの違い）を表示します
  • 抽出した一覧をテキストファイル（.txt）で保存したり、クリップボードへコピーしたりできます

向かないこと・注意

  • ファイルの中身は開きません。名前の形だけで比べるため、内容が同じかどうかは分かりません
  • ファイルの削除、移動、名前の変更は行いません
  • 取り込めるファイル名は 10,000件までです。名前リストファイルは 10MB 以下の .txt / .csv に対応しています
  • Safari 16.4 未満のブラウザでは動作しません

なぜ作ったか

ファイル整理の前に、コピーや日付違いで増えたファイルを一覧にして見比べるためです。名前と場所だけを使い、処理はブラウザの中で完結します。削除や変更を行わない確認専用の道具として作りました。
