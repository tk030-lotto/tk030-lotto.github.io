PDF結合（PDF Merger）

ブラウザ内で複数のPDFを1つに結合するツール

ツールを利用する / コードを見る

ツールを開く（Web版） GitHub リポジトリ note 解説記事（準備中）

こんなときに

複数のPDFファイルを、1つのPDFにまとめたいときに使います。社外の文書や個人情報を含むPDFを、外部のオンライン結合サービスに預けず、手元のブラウザの中だけで結合できます。

できること

  • 複数のPDFをドラッグ＆ドロップ、または「ファイルを選択」で追加できます。
  • 追加すると、ファイルごとのページ数が表示されます。
  • 「▲」「▼」で結合の順番を入れ替え、「✖」で一覧から外せます。
  • 「保存ファイル名」の欄で、結合後のファイル名を決められます（初期値は 結合_日付.pdf）。
  • 壊れたPDF、ページがないPDF、パスワード付きのPDF、PDF以外のファイルは、赤字で理由が表示され、結合の対象から外れます。

向かないこと・注意

  • しおり（ブックマーク）、フォームの入力欄、タグなどは、結合後に引き継がれない場合があります。
  • パスワード付きのPDFは結合できません。先にパスワードを外してください。
  • 追加したファイルの合計が約200MBを超えると、結合の前に確認のメッセージが表示されます。

なぜ作ったか

社外秘文書や個人情報を含むPDFファイルを、外部のオンライン結合サービスにアップロードせず、手元のパソコン（ブラウザ内）だけで結合できたらと思い、作りました。ファイルの内容は外部に送信されません。画面を開いたあとの処理は、お使いのブラウザの中で行われます。
