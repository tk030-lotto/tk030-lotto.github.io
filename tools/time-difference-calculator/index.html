時差・現地時刻比較ツール

Time Difference Calculator

ツールを利用する / コードを見る

ツールを開く（Web版） GitHub リポジトリ note 解説記事（準備中）

こんなときに

海外の家族や知人、取引先に連絡する前に、現地が何時で何曜日かを確認したいときに使えます。海外旅行や出張の予定を立てるときに、数時間後や数時間前の現地時刻を並べて確かめたい場面にも向いています。

できること

  • 日本・アジア・北米・ヨーロッパ・オセアニアの32都市から、「基準都市 A」と「比較都市 B」を選んで現地時刻を比較できます。
  • 時刻（時・分・秒）、日付・曜日、午前/午後、UTCオフセット、夏時間（☀️ 夏時間 (DST)）を1秒ごとに更新して表示します。
  • 2都市の時差と、日付の関係（「同日」「翌日」「前日」など）を中央のカードに表示します。
  • 中央の「入替」ボタンで、都市Aと都市Bを入れ替えられます。
  • 「時刻シミュレーター」のスライダーで、現在時刻の前後24時間（15分刻み）の現地時刻を確認できます。

向かないこと・注意

  • 対象は収録済みの32都市のみです。自由入力で都市を検索したり追加したりはできません。
  • 時刻と夏時間（DST）の算出は、ブラウザのタイムゾーン定義と端末の時計に依存します。
  • 夏時間判定は1月1日と7月1日のオフセット比較によるため、負の夏時間や年途中の恒久的なオフセット変更には対応していません（現行32都市では発生しません）。
  • 選んだ都市やシミュレーション時刻は保存されません。ページを再読み込みすると初期状態（東京・ニューヨーク・現在時刻）に戻ります。
  • 外部のAPIやサーバー、外部フォントには通信せず、ブラウザ内だけで動作します。

なぜ作ったか

外部のAPIやサーバーを使わず、ブラウザを開くだけで2都市の現地時刻と日付のずれを並べて確認できる道具として作りました。アカウント登録や設定を省き、ページを開いてすぐ比べられる形にしています。
