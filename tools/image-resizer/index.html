画像一括リサイズ（Image Resizer）

複数の画像の長辺をそろえて、まとめて縮小

ツールを利用する / コードを見る

ツールを開く（Web版） GitHub リポジトリ note 解説記事（準備中）

こんなときに

ブログ、SNS、フリマに出す写真の大きさを、そろえたいときに使います。メールや資料に貼る画像のファイルサイズを、まとめて小さくしたいときにも使います。1枚ずつ画像ソフトで開いて縮小する作業を、1回の操作にまとめます。

できること

  • 複数の画像を、ドラッグ＆ドロップまたはファイル選択で、まとめて追加します。
  • 長辺のピクセル数を指定して、縦横比を保ったまま縮小します。初期値は 1280 です。
  • 長辺が指定サイズ以下の画像は、拡大せず、元のサイズで出力します。
  • スマホで撮った写真は、記録された回転情報を読み取ってから、縦横を決めます。
  • 同じ名前のファイルがあるときは、image_001.jpg のように連番を付けて保存します。元のファイルは書き換えません。

向かないこと・注意

  • 対応形式は JPG、JPEG、PNG、WebP です。GIF、BMP、HEIC は、あらかじめ対応形式に変換してから追加します。
  • 長辺は、1〜20000 px の整数で指定します。
  • JPEG と WebP は、品質 0.92 で書き出します。撮影日時や位置情報は、出力した画像に残りません。
  • 枚数が多いと、端末のメモリ不足で、処理が重くなったり失敗したりすることがあります。その場合は、枚数を分けて処理します。
  • フォルダへの直接保存は、PC の Chrome と Edge で使えます。Firefox、Safari、スマートフォンでは、ZIP ファイルでダウンロードします。
  • 通信しません。画像と設定は、お使いのブラウザの中で処理します。

なぜ作ったか

複数の画像を、長辺のピクセル数を指定して、まとめて縮小する機能がほしくて作りました。1枚ずつ画像ソフトで開いて縮小すると、枚数に比例して手間が増えます。このツールは、長辺を1回指定して、複数の画像を一度に縮小します。
