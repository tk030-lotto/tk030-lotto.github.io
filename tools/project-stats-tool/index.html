プロジェクト統計ツール

プロジェクトの行数・言語構成を集計

ツールを利用する / コードを見る

ツールを開く（Web版） GitHub リポジトリ note 解説記事（準備中）

こんなときに

開発中のプロジェクトや手元のリポジトリについて、総行数とファイル数を把握したいときに使います。どの拡張子やディレクトリが多くを占めるかも、同じ画面で確認します。

できること

  • フォルダを選ぶか、画面にドラッグ＆ドロップして、中のファイルを読み込みます。
  • 総行数・コード行・コメント行・空行・ファイル数・ディレクトリ数・容量・平均行数を集計します。
  • 拡張子別の表、ディレクトリ別の表、行数順とサイズ順の上位10ファイル、検索と絞り込みができる全ファイル一覧を表示します。
  • 結果を Markdown（コピー）、CSV（保存）、JSON（保存）で出力します。

向かないこと・注意

  • 行数とコメント行は、行頭の記号を見て判定します。文字列の中にコメントの記号があるときなどは、近い値になる場合があります。
  • ドットで始まる隠しファイル・隠しフォルダと、node_modules・dist・build などは集計しません。10 MB を超えるファイルは読み込まず、件数だけ記録します。
  • フォルダ選択ボタンが使えないブラウザでは、ドラッグ＆ドロップか、標準のフォルダ選択入力を使います。
  • 選んだファイルは端末内で処理します。外部のサービスへは通信しません。

なぜ作ったか

プロジェクトのフォルダをブラウザ上で走査し、コード量・ファイル構成・行数・言語の分布を統計として見られるようにするために作りました。AI を使った開発で、既存のプロジェクトの構造と規模、言語の構成比を把握する場面を想定しています。
