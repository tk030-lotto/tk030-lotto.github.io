個人情報マスキングツール

画像の個人情報を、ブラウザ内で黒く塗って隠すツール

ツールを利用する / コードを見る

ツールを開く（Web版） GitHub リポジトリ note 解説記事（準備中）

こんなときに

書類や会員証、名刺の写真を、人に見せたり送ったりしたいときに使います。氏名や住所、電話番号は見せたくない。SNS に上げる前に、写り込んだ個人情報だけを消したい。そういうとき、画像編集ソフトを開かなくても、ブラウザだけで済ませられます。

できること

  • 画像を選んで、隠したい場所をドラッグするだけで黒く塗れます。
  • 塗りすぎても、「元に戻す」で何度でもやり直せます。
  • 「仕上がり確認」で、塗った結果を先に確かめられます。
  • できあがった画像は、PNG で保存できます。
  • 画像は端末の中だけで処理され、外部へ送信されません。

向かないこと・注意

  • 文字を自動で見つけて塗る機能は、まだありません。いまは手で塗ってください。
  • 対応している画像は JPEG・PNG・WebP です。
  • 約1,600万画素を超える画像は、縮小して処理します。
  • 塗り残しがないかは、保存した画像をご自身で最終確認してください。

なぜ作ったか

写真を人に渡すとき、写っている個人情報を消す作業が面倒でした。画像編集ソフトを開いて、黒い四角を置いて、書き出して。その手順を、その場で数秒で終わらせたい。しかも、そのために画像をどこかのサーバーへ預けるのは避けたい。

そこで、ブラウザの中だけで完結する、塗るだけの道具を作りました。機能は多くありません。開いて、塗って、保存する。それだけです。だからこそ、安心して使えると思っています。
