こんなときに

基準日時点での満年齢を確認したいときや、指定した日数の前後にある日付と曜日を調べたいときに使えます。2つの日付のあいだの総日数や「○年○か月○日」、日付をまたぐ作業や勤務の経過時間を算出したいときにも対応しています。

できること

  • 年齢計算: 生年月日と基準日から、満年齢、経過期間（○年○か月○日）、生まれてからの総日数を算出します。
  • 日付計算: 基準日から指定日数（0〜3,650,000日）の後または前の日付と曜日を算出します。
  • 期間計算: 開始日と終了日の総日数と、暦上の期間（○年○か月○日）を算出します。
  • 時間計算: 開始時刻と終了時刻から経過時間（○時間○分）と合計分数を算出します。「翌日（日付をまたぐ計算）」のチェックで日付をまたぐ計算にも対応します。

向かないこと・注意

  • 扱える日付の範囲は 0001-01-01 から 9999-12-31 までです。
  • 日付計算で指定できる日数は 0 から 3,650,000 日の整数です。
  • 時間計算は時と分（HH:mm）の単位です。秒単位の計算には対応していません。
  • 年齢と期間の「○年○か月○日」は、開始日から年・月・日の順に終点を超えない最大まで加算し、加算先の月に同じ日がない場合は末日に丸める方式です。平年の2月29日生まれは、2月28日時点で満年齢が加算されます。

なぜ作ったか

年齢、日付、期間、時間の計算は、用途ごとに別の画面やアプリを開く手間が発生します。日常で使う4種類の計算をタブで切り替えられる1つの画面にまとめ、入力データを外部に送信せずブラウザ内だけで完結して使えるように作成しました。
