こんなときに

Excel で「行を追加したい」「値だけ貼り付けたい」といった操作のショートカットキーを、目的から探したいときに使います。矢印キーで画面全体が動く、入力した数字が勝手に日付になる、計算結果が更新されないといったトラブルの対処法も調べられます。Windows と Mac で異なるキー表記を確認したい場面にも対応しています。

できること

  • やりたいことから逆引き検索: キーワード、タグ、キー名を入力すると、13 件の項目から該当する操作を絞り込みます（入力後 150ms で反映）。
  • Windows / Mac のキー表記切り替え: 画面上部の「Windows」「Mac」ボタンで、使用している OS に合わせたキー表記へ切り替えます。
  • カテゴリ別の絞り込み: 「すべて表示」「編集・入力」「書式・値」「データ操作」「⚠️ トラブル解決」の 5 つのタブで項目を絞り込みます。
  • 端末内での動作: 入力した語句を外部へ送信せず、ブラウザ内だけで処理します。外部スクリプトや外部フォントの読み込みも行いません。

向かないこと・注意

  • 収録項目はショートカット 8 件とトラブル解決 5 件の計 13 件です。利用者が項目を追加したり保存したりする機能はありません。
  • Microsoft Excel 2019 / 2021 / Microsoft 365 を想定しています。バージョンやキーボード配列、OS の設定により、キー操作が異なる場合があります。
  • 画面上の案内のみを行うツールです。Excel ファイルを読み込んだり、直接編集したりする機能はありません。
  • 本ツールは個人が開発した非公式ツールです。無保証で提供されます（MIT License）。

なぜ作ったか

業務で Excel を使う際、ショートカットキーの名称ではなく「やりたいこと」や「起きている困りごと」から手順を引ける画面を用意する目的で作りました。Windows と Mac の両方で表記を確認でき、外部へ通信せずにブラウザだけで開ける形にしています。
