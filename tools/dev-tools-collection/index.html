開発・作業支援ツール

作りっぱなし対策ツール集

Markdownリンク検査など5機能

用途

文書やリポジトリを作成したあとに必要となる、リンク切れの確認、公開してはいけない機密情報パターンの点検、引き継ぎ文書の作成、テキストの差分比較、文書間の表記ゆれ検査を、ブラウザ内だけで実行できる5つの開発支援ツール集です。

ソフトウェア開発やドキュメント作成の現場において、作業完了後の点検や整理を手軽に行うことができます。ファイルや入力データは外部サーバーへ送信されず、お使いのブラウザ内（ローカルメモリ上）のみで安全に処理されます。

できること

  • Markdown Link Checker: Markdownファイル内の相対パスリンク、画像参照パス、ページ内見出しアンカー、外部URLの構文を検査し、リンク切れの箇所を一覧表示します。
  • GitHub Preflight: リポジトリを公開する前に、APIキーやトークン等の機密情報パターン、不要ファイル（.env, node_modules等）、大容量ファイル、未解決のデバッグコード（console.log, debugger, TODO）を点検します。
  • Handoff Pack: 作業の目的、完了項目、残課題、関連ファイルを入力し、AIエージェントやチームメンバーへの引き継ぎ用Markdown文書を3種類のテンプレート（Standard / Minimal / Full Context）から生成します。
  • Prompt Diff: 2つのプロンプトやテキストを行単位・単語単位で比較し、Side-by-Side（左右並列）またはUnified（統合）形式で可視化します。前後の空白無視や単語ハイライトの切り替えに対応しています。
  • Document Consistency Checker: 複数のMarkdown文書を横断して、用語の表記ゆれ、文書間のタスク進捗ステータスの食い違い、標準セクションの欠落、未完了のTODOやチェックリスト項目を検出します。
  • レポート出力: 各ツールの検査結果や生成文書を、Markdown、HTML、JSON、テキスト形式で保存、またはクリップボードへコピーできます。

なぜ作ったか

文書やリポジトリを作ったあとの確認には、リンクの検査、公開前の点検、引き継ぎ文書の作成、版の比較、表記の統一という作業があります。この5つの作業を、外部通信を行わずにブラウザの中だけで行える形にまとめたものです。

注意事項・限界

  • 本ツールの検査は、定義された規則およびパターンに基づく補助的なものです。機密情報の検出漏れや外部URLの到達性を保証するものではありません（外部URLは構文のみを検査します）。
  • GitHub Preflight の本文検査は、ブラウザのフリーズを防ぐため 5MB 以下のファイルに対応しています。
  • 動作環境は、Google Chrome / Microsoft Edge / Safari / Firefox の各最新版です。スマートフォンの実機での表示は、確認できていません。
  • 本ツールは現状有姿で提供されます。ツールの使用により生じたいかなる損害についても、制作者は責任を負いません。

データの扱い・外部通信

すべてのファイル読み込み、解析、生成処理はお使いのブラウザ内（ローカルメモリ上）で完結します。選択したファイルや入力したテキストが外部サーバーへ送信されることはありません。外部フォントや外部CDNへの通信も行いません。
