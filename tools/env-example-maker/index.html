.env テンプレート化ツール

env-example-maker

ツールを利用する / コードを見る

ツールを開く（Web版） GitHub リポジトリ note 解説記事（準備中）

こんなときに

プロジェクトを公開したり他の人に渡したりするとき、環境変数のキーだけを並べた .env.example を用意することがあります。元の .env から値を1つずつ手作業で消すと、消し忘れが起きやすくなります。このツールは .env の内容を貼り付けるか読み込むことで、キーだけを残して値を空にしたテキストを生成します。

できること

  • テキストの貼り付け、ファイル選択、ドラッグ＆ドロップのいずれでも .env を読み込めます。
  • コメント行（# で始まる行）と空行は、元の位置のまま残します。
  • export が付いた行は、export キー= の形のまま変換します。
  • 引用符（" または '）で囲まれた複数行の値も、キーだけを残して1行に変換します。
  • 変換結果はクリップボードへのコピー、または .env.example としてのダウンロードができます。
  • 入力した内容はブラウザの中だけで処理し、外部サーバーへの送信やブラウザへの保存は行いません。

向かないこと・注意

  • コメント行はそのまま残ります。コメントの中に実際の値を書いている場合は、共有前に取り除いてください。
  • 値の形式チェックや不要なキーの整理は行いません。同じキーが重複している場合はそのまま残ります。
  • 解釈できない行や複数行の値の2行目以降は出力されず、件数だけが表示されます。二重引用符の値が \\" で終わる形など、閉じ引用符を判定できない場合は以降の行が除外されます。

なぜ作ったか

.env を共有用の .env.example に書き換える作業は、プロジェクトを共有するたびに発生します。手作業で値を消すと見落としが起きやすいため、キーを残して値を空にする変換だけを行う単機能のツールとして作りました。入力する .env には秘密の値が含まれるため、外部通信を行わず、ブラウザの中だけで完結して動く形にしています。
